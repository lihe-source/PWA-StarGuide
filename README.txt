星空指南針 V1.0.0

部署到 GitHub Pages
1. 將本資料夾內的所有檔案上傳到 GitHub Repository 的 main 分支根目錄。
2. 在 Repository → Settings → Pages 中，將 Source 設為 Deploy from a branch。
3. Branch 選 main，資料夾選 /(root)，按 Save。
4. 等待 GitHub Pages 完成部署後，用 Safari 開啟 HTTPS 網址並加入主畫面。

首次使用
1. 點「開始觀星」。
2. 允許相機、位置及方向與動作權限。
3. 將手機移離磁性手機殼、車體、喇叭或大型金屬物品。
4. 將後置鏡頭舉向天空。空心圈代表依時間、GPS 和方向推算的位置。
5. 按下快門後，程式會分析照片亮點；綠色標記代表照片亮點與推算星位相符。

使用限制
- iPhone 首次取得方向感測權限時，必須由使用者點擊按鈕。
- PWA 相機的夜間曝光能力由 iOS/Safari 決定，可能不及原生相機夜景模式。
- 城市光害、雲層、手震、磁性手機殼與羅盤誤差會影響結果。
- 若星名固定偏離實際星點，請到設定頁調整鏡頭視角、左右偏移與上下偏移。
- 照片與辨識結果只保存在目前裝置的瀏覽器儲存空間。

版本更新
- 程式啟動時會讀取 version.json，自動檢查新版本。
- 設定頁也可手動按「檢查更新」。
- 部署新版本時，請同步修改 app.js、sw.js 與 version.json 內的版本號。
